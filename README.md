## 🛠️ Tech Stack & Architecture

### Tooling Framework
* **Core Runtime:** Python 3
* **Data Ingestion & Wrangling:** Pandas & NumPy
* **Exploratory Visual Analytics:** Matplotlib & Seaborn
* **Predictive Computation:** Scikit-learn (ML modeling & validation arrays)
* **Workspaces:** VS Code & Interactive Jupyter Notebook environments

### Data Pipeline Workflow
```mermaid
graph LR
    A[Data Ingestion] --> B[Data Cleaning & Prep]
    B --> C[Exploratory Data Analysis]
    C --> D[Model Train & Test]
    D --> E[Visualization & Reports]
```

1. **Ingestion:** Loading industrial datasets into high-performance Pandas DataFrames.
2. **Pre-processing:** Drop anomalies, strip inconsistent structural formatting, handle mixed columns, and clean outliers.
3. **Exploratory Analysis (EDA):** Computing summary matrices, distributions, and finding variables with high statistical variance.
4. **Machine Learning:** Running test splits via Scikit-learn to parse feature sets against targeted evaluation thresholds.
5. **Insights:** Outputting interactive visualizations to communicate actionable findings to engineering stakeholders.
